# K2 — مشاور هوشمند کنکور

نرم‌افزار دسکتاپ **فارسی، راست‌چین و آفلاین‌محور** برای دانش‌آموزان کنکور.

این پروژه از صفر ساخته شده و به هیچ پروژهٔ پیشینی وابسته نیست. منطق کسب‌وکار (دامنه) کاملاً از رابط کاربری جدا است، داده‌ها فقط روی همان دستگاه کاربر می‌مانند و هیچ چت‌بات آزاد، استریک، رتبه‌بندی یا تشخیص روان‌شناختی در آن وجود ندارد.

> رابط کاربری کاملاً راست‌چین است و فونت فارسی وزیرمتن همراه بسته توزیع می‌شود. تصویر نسخهٔ قدیمی تا زمان گرفتن اسکرین‌شات از رابط خالی جدید در README نمایش داده نمی‌شود.

## دانلود نسخهٔ ویندوز

### نصب‌کنندهٔ استاندارد ویندوز (روش پیشنهادی)

[**⬇ دانلود نصب‌کنندهٔ K2 برای ویندوز x64 (K2-Setup)**](https://github.com/rezaa2544/k2/raw/refs/heads/main/downloads/K2-Setup-1.0.0.exe)

فایل `K2-Setup-1.0.0.exe` را دانلود و اجرا کنید. این یک نصب‌کنندهٔ استاندارد Inno Setup است — همان چیزی که هر برنامهٔ ویندوزی دارد — و همهٔ صفحه‌های عادی را نشان می‌دهد:

1. **خوش‌آمد** — معرفی کوتاه برنامه.
2. **توافق‌نامهٔ استفاده** — متن فارسی؛ باید «می‌پذیرم» را بزنید تا ادامه پیدا کند.
3. **پوشهٔ مقصد** — پیش‌فرض `C:\Program Files\K2 Konkur Advisor`؛ می‌توانید عوضش کنید.
4. **پوشهٔ منوی Start** — پیش‌فرض «مشاور هوشمند کنکور»؛ قابل تغییر است.
5. **گونهٔ نصب** — «نصب کامل» (برنامه + راهنمای کاربر) یا «نصب دلخواه» که اجزای اختیاری را دستی انتخاب می‌کنید.
6. **کارهای افزودنی** — میان‌بر میزکار (برای همهٔ کاربران یا فقط من) و «هیچ پوشه‌ای در منوی Start ساخته نشود».
7. **آمادهٔ نصب → نصب → پایان** — در صفحهٔ آخر تیک «خواندن راهنمای کاربر» هست تا راهنما در مرورگر پیش‌فرض باز شود.

پس از اتمام نصب، میان‌بر `K2 Konkur Advisor` روی میزکار و در فهرست شروع ویندوز ساخته می‌شود و برنامه بلافاصله اجراشدنی است. نصب به‌صورت پیش‌فرض در `Program Files` و برای همهٔ کاربران انجام می‌شود.

نصب‌کننده در «تنظیمات ← برنامه‌ها» ویندوز با نام، ناشر، نسخه، آیکن، توضیح و نشانی وب ثبت می‌کند و دکمهٔ **حذف نصب** استاندارد ویندوز را می‌آورد. حذف نصب فقط فایل‌های برنامه را پاک می‌کند؛ **داده‌ها و تنظیمات شما در پوشهٔ دادهٔ کاربر دست‌نخورده می‌مانند** تا اگر دوباره نصب کردید، همه‌چیز سر جایش باشد. راهنمای کاربر هم داخل `{app}\docs\USER_GUIDE.html` نصب می‌شود و آفلاین خوانده می‌شود.

**اگر ویندوز هشدار SmartScreen داد** (چون فایل امضای دیجیتال ندارد): روی «اطلاعات بیشتر» و بعد «اجرا روی هر حال» بزنید. این هشدار به‌خاطر نبود امضاست، نه به‌خاطر خرابی فایل.

> **صادقانه:** نصب‌کننده هنوز امضای دیجیتال ندارد، چون گواهی Code Signing خرید و تأیید هویت می‌خواهد. خط لولهٔ `signtool sign` + `verify` در CI پیاده و **آزموده** شده؛ به‌محض افزودن گواهی به سکرت‌های مخزن، همان گام خودکار اجرا می‌شود. تا آن زمان ممکن است SmartScreen ویندوز هشدار بدهد — برای دور زدن، روی «اطلاعات بیشتر» و بعد «اجرا روی هر حال» بزنید. جزئیات: `docs/RELEASE_AND_WINDOWS_PACKAGING.md` بند ۱۱.

[**⬇ دانلود نسخهٔ HTML**](https://github.com/rezaa2544/k2/raw/refs/heads/main/downloads/K2-preview-html.zip) · [مشاهدهٔ فایل در مخزن](downloads/K2-preview-html.zip) · [مشاهدهٔ سورس HTML](preview/K2-preview.html)

## نصب و اجرا (ویندوز)

نسخهٔ آماده: پوشهٔ `K2/` را باز کنید و `K2.exe` را اجرا کنید. نیازی به نصب پایتون نیست.

ساخت از روی سورس (روی ویندوز ۱۰/۱۱ با Python 3.12):

```powershell
powershell -ExecutionPolicy Bypass -File .\packaging\build_windows.ps1
```

اسکریپت بالا: محیط مجازی می‌سازد → وابستگی‌ها را نصب می‌کند → **تست‌ها را اجرا می‌کند** → با PyInstaller می‌سازد → و در پایان **EXE را واقعاً اجرا می‌کند** و در صورت خطا build را ناموفق اعلام می‌کند.

خروجی: `packaging/output/K2/K2.exe`

## اجرا از سورس (لینوکس/مک/ویندوز)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt
export PYTHONPATH="$PWD/src"
python -m k2                     # اجرای رابط گرافیکی
python -m k2 --db /tmp/k2.db --headless   # اجرای بدون نمایشگر (سرویس/تست)
```

## اجرای تست‌ها

```bash
export PYTHONPATH="$PWD/src"
export QT_QPA_PLATFORM=offscreen
python -m pytest tests -q
```

## اصول علمی و اخلاقی محصول

این نرم‌افزار **ابزار یادگیری** است، نه پزشک و نه مشاور روان‌شناختی.

* **بازیابی فعال و تمرین فاصله‌دار** بر بازخوانیPassive اولویت دارد — این یک ترجیح مبتنی بر شواهد است، نه یک تضمین عددی.
* همهٔ اعداد تجربی (حاشیهٔ ۲۰٪، سقف جبرانی ۳۰٪، آستانه‌های تسلط، ضرایب مرور) **فرضیه** برچسب خورده‌اند و در `تنظیمات` قابل تغییرند.
* هیچ داده‌ای دربارهٔ تاریخ رسمی آزمون، ضرایب، قوانین، تعداد سؤال یا نمرهٔ منفی **حدس زده نمی‌شود**. ضرایب آزمون ۱۴۰۶ از متن کامل اطلاعیهٔ منتسب به سنجش که باشگاه خبرنگاران جوان بازنشر کرده وارد شده؛ بازیابی مستقیم میزبان اولیهٔ سنجش و پیوستِ ضرایب عددیِ تک‌درس سوابق در این محیط موفق نشد. این محدودیت در UI و `docs/OFFICIAL_TEXTBOOK_CROSSCHECK.md` صریح است.
* تشخیص پزشکی/روان‌شناختی، استریک، مقایسهٔ اجتماعی و رتبه‌بندی وجود ندارد. گزارش «فشار برنامه» فقط رفتار سیستم را توصیف می‌کند و صریحاً غیرتشخیصی است.
* موتور برنامه‌ریزی قاعده‌محور و توضیح‌پذیر است؛ CP-SAT فقط در صورت اثبات ناکافی بودن روش فعلی و پس از بنچمارک مستند اضافه می‌شود (SCH-06).
