## ۴. قواعد پذیرش مشترک

هر تست پذیرش برای این نیازمندی‌ها باید این چهار شرط را رعایت کند:

1. **بدون حدس** — ورودی معلوم، خروجی قطعی.
2. **قابل تکرار** — بدون وابستگی به زمان واقعی، شبکه یا فایل بیرونی.
3. **مرتبط** — همان رفتاری را می‌سنجد که در نیازمندی آمده.
4. **مستند** — نام تست باید صورت رفتار را بگوید (مثلاً `test_activity_never_disappears_across_a_week`).

تست ضعیف‌شده، تست حذف‌شده یا assertion بی‌صدا حذف‌شده، نقص محسوب می‌شود.
