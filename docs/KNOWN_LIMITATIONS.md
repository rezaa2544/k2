## ۵. محدودیت‌های آگاهانهٔ دامنه (توضیح‌داده‌شده، نه نقص)

1. **همهٔ اعداد تجربی فرضیه‌اند.** حاشیهٔ ۲۰٪، سقف جبرانی ۳۰٪، آستانه‌های تسلط، ضرایب اولویت و بازه‌های مرور از مطالعهٔ این کاربر مشتق شده‌اند، نه از قانون علمی. همه در `config.py` با برچسب `[H]` و در تنظیمات قابل تغییرند.
2. **تاریخ رسمی آزمون حدس زده نمی‌شود.** نمونهٔ «۳۰ مهر» سال ندارد و سالی برایش ساخته نمی‌شود؛ وضعیت تاریخ (رسمی/تخمینی/نامشخص) کاربر تعیین می‌کند.
3. **تعارض یکشنبه باز می‌ماند** تا کاربر مشخص کند کدام کلاس واقعاً برگزار می‌شود (D-004).
4. **برنامهٔ نمونه داده است، نه منطق** (D-019).
5. **هیچ تشخیص پزشکی/روان‌شناختی** — نشانگر «فشار برنامه» فقط رفتار سیستم را توصیف می‌کند.
6. **بدون چت‌بات آزاد، استریک یا رتبه‌بندی** (NFR-01، NFR-02).
7. **هفتهٔ شنبه‌محور** — اگر کاربر هفتهٔ دیگری بخواهد، باید در `jdate.weekday_index` تغییر کند.

## ۶. دستورهای دقیق برای push کردن مخزن

مخزن `rezaa2544/k2` در حال حاضر روی GitHub وجود ندارد یا خصوصی است (بازرسی `https://api.github.com/repos/rezaa2544/k2` و `https://github.com/rezaa2544/k2` هر دو ۴۰۴ برگرداندند). در این محیط هیچ اعتبارنامه‌ای برای احراز هوی git وجود نداشت، بنابراین **مخزن ساخته نشد و چیزی push نشده است**.

`gh` (نسخهٔ ۲.۴۶.۰) در این محیط **نصب شده است** و با یک دستور کار می‌کند:

```bash
gh auth login
gh repo create rezaa2544/k2 --private --source=. --remote=origin --push
```

تلاش خودکار در این محیط انجام شد و با خطای
`You are not logged into any GitHub hosts` رد شد — یعنی مشکل نبود ابزار، نبود احراز هویت بود.

اگر فقط git در دسترس است:

```bash
cd /home/user/k2
git remote add origin https://github.com/rezaa2544/k2.git
# توکن با دسترسی repo: https://github.com/settings/tokens
git push -u origin main
```

پس از push:

```bash
gh run watch          # اجرای گردش‌کار build-windows روی windows-latest
gh release create v1.0.0 release/K2-windows-x64.zip --draft
```

**این مخزن تازه است؛ اگر بعداً مخزنی با همین نام و محتوای متفاوت وجود داشته باشد، نباید حذف یا بازنویسی شود.**
