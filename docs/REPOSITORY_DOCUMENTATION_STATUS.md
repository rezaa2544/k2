# وضعیت مستندسازی مخزن

## کار انجام‌شده در این بسته
- چهار فایل اصلی ZIP استخراج شده و بدون تغییر در `source_research/` نگهداری شده‌اند.
- تحقیقات محقق و تحقیق قبلی دستیار در اسناد تجمیعی ترکیب شده‌اند.
- دسته‌بندی محصول، کاتالوگ نیازمندی‌ها، برنامه بخش ۳، برنامه ثابت اولیه، تصمیم‌های شواهد، نقشه اجرا و پرامپت عامل برنامه‌نویس تهیه شده‌اند.

## محدودیت فعلی
این مستندات در یک بسته آماده انتقال به مخزن تهیه شده‌اند؛ هنوز در Git repository مشخصی commit/push نشده‌اند، چون آدرس/مسیر مخزن اختصاصی نرم‌افزار مشاور کنکور در همین درخواست ارائه نشده است. پروژه Payesh که در سابقه وجود دارد، محصول دیگری است و بدون دستور روشن نباید مستندات این اپ به آن وارد شود.

## اقدام لازم برای ثبت واقعی
پس از مشخص‌شدن آدرس مخزن درست:
1. branch، HEAD، worktree و سیاست‌های جاری مخزن را بررسی کن.
2. اسناد موجود را بخوان و از ایجاد فایل تکراری/تعارض نام جلوگیری کن.
3. فایل‌های این بسته را با ساختار مستندات مخزن ادغام کن؛ منبع‌های اولیه را حفظ کن.
4. README یا index مستندات را به این اسناد پیوند بده.
5. diff را بررسی کن، لینک‌ها و شناسه‌های نیازمندی را اعتبارسنجی کن و commit معنادار بساز.
6. push نکن مگر اینکه کاربر صریحاً اجازه دهد.
